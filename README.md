# ХРУСТ — мобильный сайт кафе-пекарни

Онлайн-меню без заказа и оплаты: фото, цены, вес и калорийность блюд.

React + TypeScript + Vite + Tailwind CSS v4 + Lucide + React Router.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — и адрес в локальной сети, чтобы открыть с телефона
npm run build      # сборка в dist/
npm run preview    # проверить сборку
```

Чтобы открыть сайт с телефона, подключите его к той же Wi‑Fi сети и откройте адрес `Network: http://192.168.x.x:5173`, который покажет `npm run dev`.

## Структура

```
src/
  data/menu.ts        — категории и блюда (названия, цены, вес, ккал из Яндекс Еды)
  data/cafe.ts        — контакты и ссылки (неподтверждённые поля = null → заглушка в интерфейсе)
  components/         — Header, SideMenu, Chips, DishCard, DishRow, DishImage
  pages/              — Главная, Меню, Блюдо, Завтраки, О нас, Контакты, Соцсети, QR, Документы
public/dishes/        — фото блюд, вырезанные из скриншотов меню (без элементов интерфейса)
```

## Что заполнить перед показом владельцу

- `src/data/cafe.ts`: адрес, телефон, часы работы. Кнопка «Построить маршрут» и «Позвонить» включатся автоматически.
- `publicMenuUrl` — после публикации сайта; сейчас на экране QR демонстрационный код.
- Фото интерьера для «О нас» (`src/pages/About.tsx`), сейчас — реальное фото подачи.
- Описания и составы блюд (`description`, `composition` в `menu.ts`) — блок «Состав» появится сам.
